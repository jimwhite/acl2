ACL2 on WebAssembly

ACL2 built on ECL compiled to WebAssembly, with the prover's own functions and certified books ahead-of-time compiled to wasm modules that ECL loads at run time.

Pages

  • ECL smoke test Instantiates the wasm ECL and evaluates a couple of forms. ~1 s.
  • Dynamic linking Loads a compiled Lisp module into the running ECL in the page and calls its functions. ~0.4 s.
  • ACL2 Preloads ACL2 and starts it. Reaches the boot strap and then stops: see the note below.

Loading a compiled module in a page works (see Dynamic linking), and the ACL2 page preloads the whole AOT tree and starts the boot strap.

The remaining gap

ACL2 does not finish starting in a page. The boot strap needs 2–4 MB of the engine's native stack, and a web page gets about 1 MB; the depth comes from ECL's interpreter running ACL2's boot-strap event forms. Nothing in the page can raise that limit. The same build starts normally under Node, which can be given a larger stack (node --stack-size=524288).

So the work ahead is to reduce that recursion — or to ship a base that does not boot-strap in the page at all. Details, measurements and the two bugs that made the AOT path work are in WASM-PORT-NOTES.md and wasm/web/README.md in the repository.
