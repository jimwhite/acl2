Milawa on WebAssembly

Milawa's standalone proof checker, compiled to WebAssembly with ECL. It restores a checkpoint of the checker's own history and replays commands from Milawa's utilities level, reading and checking the proof files in this page.

What is happening


Milawa is a verified proof checker for ACL2, written (and proved) by Jared
Davis. This page runs its standalone kernel, milawa.lsp, which is a
Common Lisp program. ECL is compiled to wasm32-unknown-emscripten,
the kernel is cross-compiled ahead of time with the same ECL, and the two are
linked into a single module. The page writes the base image
(state.lisp, the checker's arity table, axioms, theorems and the
definitions it has admitted), the events and the proof files into an in-memory
filesystem, then starts the checker.


Only the checker runs here. Building the levels from scratch needs the ACL2
proof builder, which does not fit in a page; the proofs above were built
offline and are checked by the wasm checker.
