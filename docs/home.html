About ACL2

ACL2 (A Computational Logic) is a programming language, specification language, and mechanical theorem prover. It is designed for the formal verification and validation of hardware and software systems.

Features

  • Automated reasoning and theorem proving
  • Functional programming language based on Lisp
  • Comprehensive proof checking
  • Industrial-strength formal verification
  • Active development and community support
